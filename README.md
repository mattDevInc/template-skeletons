Dependancies:
Runs with Python 3.12. Libraries:
- Numpy
- Open3D
- Plotly
- Point-Cloud-Utils
- OS
- Skeletor
- Pandas
- Copy
- Time
- Scipy

Simplest way to run: navigate to main() method and uncomment section of code for one of the algorithms AND lines 596 - 606. E.g. for the Wavefront algorithm the lines to uncomment are: 610 - 618. Check the accepted parameters for any of the algorithm methods (wavefront_pipeline_one_dataset, tangent_ball_pipeline_one_dataset, mean_curvature_pipeline_one_dataset, teasar_pipeline_one_dataset, vertex_clusters_pipeline_one_dataset) to show progress, show visualised outputs etc.
